# 📊 Análise de Vendas com Python

## 🎯 Sobre o projeto

Este projeto apresenta uma análise exploratória de dados fictícios de vendas de produtos de informática, desenvolvida com Python.

O objetivo é calcular indicadores de desempenho comercial, identificar os produtos com maior faturamento e quantidade vendida e apresentar os resultados por meio de gráficos e um dashboard interativo.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- ipywidgets
- Google Colab
- GitHub

## 📈 Principais resultados

| Indicador | Resultado |
|---|---|
| Faturamento total | R$ 22.800,00 |
| Unidades vendidas | 43 |
| Produto com maior faturamento | Notebook |
| Produto mais vendido em unidades | Mouse |

## 🔎 Conclusões da análise

O Notebook apresentou o maior faturamento, com R$ 12.500,00, representando aproximadamente 54,8% da receita total.

O Mouse foi o produto mais vendido em quantidade, com 20 unidades.

A análise demonstra que um produto com maior volume de vendas não necessariamente gera o maior faturamento.

## 💻 Funcionalidades

- Criação e manipulação de dados com Pandas
- Cálculo de faturamento por produto
- Gráficos de barras com Matplotlib
- Indicadores de faturamento e quantidade vendida
- Filtro interativo para selecionar produtos

## ▶️ Como executar o projeto

1. Abra o arquivo `Analise_de_Vendas_Python.ipynb` no Google Colab.
2. Execute as células na ordem apresentada.
3. Visualize os gráficos e explore os filtros interativos.

Os filtros interativos funcionam durante a execução no Google Colab, mas não diretamente na pré-visualização do GitHub.
